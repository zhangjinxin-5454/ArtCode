# 常见问题

---

## 安装与启动

**Q：安装包下不动 / 一直转圈？**
安装包 163 MB，走内网宽带正常。断点续传的话重新下载即可。

**Q：装完双击没反应？**
- 先确认系统是 Windows 64 位（右键「此电脑」看系统类型）
- 检查 Windows Defender 有没有拦截（偶尔会误报 Electron 应用）
- 右键以管理员身份运行一次试试

**Q：装完想换运行模式？**
装完在首屏可以选「独立使用 / 与 ZCode 共生」，两个模式功能完全一致。
之后想切换：设置 ▸ 数据与模式。

**Q：能同时装官方 ZCode 吗？**
能，两者的应用 ID 不同，Windows 不会把它们互相覆盖。
但如果用「与 ZCode 共生」模式，**别同时开着两个**——它们共用同一个数据库，会互斥锁，
后启动的会等锁。关掉一个再开另一个即可。

**Q：哪些系统能用？**
Windows 10 21H2（版本 19044）及以上，或 Windows 11。
更低的版本（如 20H2）安装器会直接提示不支持并拒绝安装——新版内核（Chromium 152）不再支持旧系统；
已有的旧版本应用仍可继续使用，但收不到后续更新。

**Q：新版本收不到自动更新 / 更新失败？**
手动更新：到 [Releases](../../releases/latest) 下载最新安装包，**覆盖安装**即可，数据不受影响。
（国内网络直连 GitHub 不稳时自动更新会失败；新版起更新已走国内镜像，旧版本用户手动更新一次即可。）

## 授权

**Q：一定要激活吗？**
基础功能（连模型、对话、工作台）不激活也能用。**但内置技能资产必须激活**：技能包是加密下发的，
未激活过的机器上**不解密、不落盘**——也就是说，**没有激活码就调不出内置的渗透方法论与知识库卡片**。
激活后自动解密启用。
详见 [激活与授权](激活与授权.md)。

**Q：换电脑了怎么办？**
机器码会变，需要重新申请一份授权。

**Q：激活码会被人盗用吗？**
授权码**绑定机器码**，别人拿到也用不了（会提示"授权不匹配本机"）。
但反过来也一样——如果别人同时拿到你的机器码和你机器上的授权文件，那拦不住。
所以别把授权文件随便发人。

## 数据与隐私

**Q：我的数据在哪？卸载会丢吗？**
独立模式在 `~/.artcode`，共生模式在 `~/.zcode`——都是你 HOME 下的普通文件。
**卸载应用不删数据**，重装后还在。

**Q：会上传我的东西吗？**
不会。资产、漏洞、报告、对话、记忆全部存储在本机（独立模式 `~/.artcode`，共生模式 `~/.zcode`），
Art Code 发行方没有服务器，不收集、不留存你的任何数据。

只有这几种情况会联网，发什么都在这里列清楚：

1. **调用云端模型**——提问与相关上下文发给所选模型供应商；用本地模型则完全不出网；
2. **z.ai 登录 / 编码套餐**——认证信息与用量请求发往 z.ai；不登录、只用自己的 API Key 可完全避免；
3. **检查更新**——向 GitHub 查询新版本，只带版本号、平台/渠道等更新所需信息，不含工作数据；
4. **你主动点「分享」或提交反馈**——只发送你在该操作中选择提交的内容。

除此之外，一切数据不出本机。

**Q：Art Code 会不会动我 ZCode 里的文件？**
独立模式下不会碰 ZCode 任何文件。
共生模式下**共用**同一份数据（同看同写），但 Art Code 只在文件**不存在**时才写自己的默认版本，
你自己写的内容一个字不动。

**Q：我自己的 AGENTS.md 会被覆盖吗？**
不会。只在缺失时种入默认版。你写的（哪怕是从别的工具迁过来的）都原样保留。

## 渗透工作台

**Q：为什么面板上少了一个目录？**
刚建的目录（还没有报告/资产）也会出现在导航列里，计数为 0。
如果连行都没有：确认它在桌面根目录下、或已通过「导入任务目录」指定；
再看「扫描提示」徽标是否报了格式原因。

**Q：我的报告格式没被认出来？**
报告等级要能认出来，写法见 [使用教程 §三](使用教程.md)。
都不写的话会归到「未分级」——单独一档，不会丢，但统计上不区分严重性。

**Q：Excel 另存的清单能认吗？**
能。分隔符和编码自动嗅探，见 [使用教程 §三](使用教程.md)。
带表头的必须有主机列，列名写 `host` / `域名` / `资产` 都认。

**Q：任务目录能选到别的盘吗？**
能，点目录名切换，或用「浏览…」选任意位置，会自动导入并绑定。
不想绑了点「解除绑定」退回自动判定。

**Q：批量派发跑到一半断了？**
流程树支持无人值守续跑，重新进来会接着上次的进度继续。

## 模型与网络

**Q：连不上模型？**
- 检查 API Key 有没有过期
- 共生模式下确认 ZCode 那边能正常连（两者用同一份配置）
- 有些网络需要代理：设置 ▸ 网络 里配

**Q：能不能接自己的模型（Ollama / 兼容 API）？**
能，只要兼容 OpenAI 格式，在 设置 ▸ 模型供应商 里加一个自定义供应商即可。

**Q：Art Code 会去连 ZCode 官方的更新通道吗？**
**绝对不会。** 未配置自有更新源时更新功能是完全禁用的，
就是为了避免误连官方通道弹出官方安装包把 Art Code 覆盖掉。

**Q：登录、编码套餐这些服务是谁提供的？出问题怎么办？**
登录、编码套餐、会话分享走的是 **z.ai 的在线服务**（Art Code 基于其生态二次开发，这些属配套能力，可用性随上游）。

授权码、激活、内置技能资产与全部本地功能（作战台 / 对话 / 记忆 / 文件）属 **Art Code 自有体系**，由发行方承诺。

若上游服务变更导致相关功能受影响：会在**本仓库（README 与 Releases）公告**并尽力在后续版本适配；不依赖上游的功能不受影响。
