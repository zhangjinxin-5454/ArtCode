# 激活与授权

Art Code 采用**机器码绑定授权**：一份激活码对应一台电脑。

---

## 激活流程（三步）

### 第 1 步：拿到你的机器码

安装后首次启动，首屏（连接账号页）**上方**有一张「**机器码注册**」卡，
里面那串 32 位字符就是你的机器码。点旁边的「复制」按钮。

设置 ▸ 关于 里也能找到同一串。

找不到那张卡、或者想把机器码存下来？到 [Releases](../../releases/latest) 下载附件
「**ViewMachineCode.bat**」（查看机器码），**双击运行**即可显示并自动复制到剪贴板（需先安装并启动过一次 Art Code）。

### 第 2 步：换激活码

把机器码发给作者（**438251623@qq.com**），你会收到一串这样的东西：

```
ART1.eyJsaWNlbnNlZSI6IuiHqua1i-WuouaItyIsIm1hY2hpbmVJZCI6Ii4uLiJ9.6cdszvd_4R9iKscpQXu3j6sOQIQ4VbTKE7gbA0DUTZXy7Hsq0nVB87dLjHJeLjPJAbI01IPd8InndGXyc6hjAw
```

一整串复制好，别在中间换行。（`ART1.` 开头，中间两个 `.` 分隔）

### 第 3 步：粘贴激活

回到那张注册卡，把激活码粘进输入框，点「**激活**」。

- **立即生效，不需要重启**
- 成功后卡片会收成一行：`已激活 · 授权给 xxx，有效期至 xxxx`
- 激活后**内置技能资产会自动解密启用**

---

## 不激活会怎样

**不激活也能正常用。** Art Code 的基础功能——连模型、多智能体协作、对话、记忆、
渗透工作台——都不需要激活。

激活解锁的是：

- 内置技能资产（渗透测试方法论、检查清单、知识库卡片）
- 后续版本的商业功能

**注意内置技能资产是"必须激活才可用"的**：技能包随授权**加密下发**，未激活过的机器上**不解密、不落盘**——
也就是说，**没有激活码就调不出内置技能**（不是"显示出来但打不开"，是内容根本不出现在磁盘上）。
激活后自动解密启用；已激活过的机器上，落盘的技能之后一直可用。

换句话说：**基础功能不激活也能用；激活码买的是"进阶内容"（内置技能资产 + 商业功能）。**

---

## 服务边界（承诺到哪里）

激活解锁的**内置技能资产**与全部**本地功能**由 Art Code 承诺：一次激活、长期有效，不依赖任何在线服务。

登录、编码套餐、会话分享等能力走 **z.ai 的在线服务**（第三方），不属于授权承诺范围——可用性随上游；若上游调整导致受影响，会在本仓库（README 与 Releases）公告并尽力适配。

一句话：**买断的是本地能力与内置资产；在线服务是随上游附带的便利。**

## 常见激活问题

**Q：提示"激活码换机器被拒"？**
授权是绑机器的。如果你在 A 电脑申请的码拿到 B 电脑用，会被拒。
换机器 / 重装系统后机器码会变，需要重新申请一份。

**Q：提示"授权已过期"？**
授权到期了。联系作者续期，会给你新码。

**Q：提示"签名无效"？**
码被截断了（复制时少字符），或者中间混进了空格/换行。
重新复制完整的一整段。

**Q：粘贴报"既不是激活码，也不是有效的授权文件"？**
检查是不是少了开头。必须以 `ART1.` 开头、以 `.` 分成三段。

**Q：找不到「机器码注册」这张卡？**
说明你用的构建不含授权门槛，那张卡不会渲染，功能也不打折。
从 [Releases](../../releases/latest) 下载的正式发行包才有。

**Q：授权文件在哪？**
`~/.artcode/license.json`（即 `C:\Users\你的用户名\.artcode\license.json`）。
这个文件和 ZCode 的目录无关，ZCode 读不到你的授权。

## 授权是怎么防伪造的

- 授权内容由**私钥**签名（Ed25519），应用里只内置**公钥**做验签
- 没有私钥就造不出有效签名——这是数学上不可伪造的，不是靠代码保密
- 验签三件事一起过：签名有效 + 没过期 + 机器码匹配
- 篡改码里任何一个字符，签名立刻失效

### 已知边界（如实说明）

- 逆向者能看到验签逻辑和公钥。防线是**签名不可伪造**，不是"别人看不懂代码"。
- 纯离线验签理论上可以被 patch 绕过。Art Code 用多层加载 + 每次更新重新编译抬高门槛，
  但**不能承诺绝对防破解**。
- 要更高强度需要在线心跳校验，那需要一台服务器。当前离线模型覆盖
  「授权可控、伪造不了」这个需求。
