# 模型接入指南

Art Code **推荐用自己的 API Key 接模型**：即时生效、不依赖任何账号体系、用量完全自己掌控。
z.ai 官方本就支持任意第三方工具用 API Key 接入（Claude Code、Cline 等工具的官方文档都是这么教的），放心用。

---

## 方式一：z.ai 官方 API（推荐，GLM 系）

1. 到 **z.ai 控制台**（国际版 z.ai / 国内智谱开放平台 BigModel）创建 **API Key**；
2. Art Code → 设置 ▸ 模型供应商 → 添加自定义供应商：
   - 类型：**Anthropic 兼容**（以界面实际选项为准）
   - Base URL：`https://api.z.ai/api/anthropic`
   - API Key：粘贴你刚创建的 Key
3. 选模型（GLM-5.x 系列）→ 发消息测试。

> 已订阅 **GLM Coding Plan** 的用户：控制台生成 API Key 即可按上面步骤使用，
> 订阅额度照常生效——这正是官方为第三方工具提供的接入方式。

## 方式二：DeepSeek（性价比之选）

1. 到 **platform.deepseek.com** 创建 API Key；
2. 设置 ▸ 模型供应商 → 添加自定义供应商：
   - 类型：OpenAI 兼容
   - Base URL：`https://api.deepseek.com`
   - API Key：粘贴你的 Key
3. 选模型（deepseek-chat / deepseek-reasoner）→ 测试。

## 方式三：任意 OpenAI 兼容端点

BigModel、SiliconFlow、OpenRouter、中转站、本地 Ollama……
只要是 OpenAI 兼容格式：添加自定义供应商 → 填 Base URL + Key → 选模型。本地模型同理（如 `http://127.0.0.1:11434/v1`），配好后**断网也能用**。

## 之前用「账号登录 / 编码套餐」被风控了？

提示 `unusual activity` / `provider_code=3012` 等，是「账号登录走官方客户端专用通道」这条路的平台风控，与 Art Code 本身无关。

**自救路径：改走方式一（官方 API Key）**——这是官方为第三方工具开放的正规通道，配好后即稳。
账号本身一般不受影响；若控制台有异常提示，按平台指引处理即可。

## 关于「与 ZCode 共生」

共生的定位是**共用数据与登录态、平滑迁移历史**，方便老 ZCode 用户无缝搬家。
**模型接入这件事，推荐一律走上面的自带 Key 方式**——不依赖任何账号通道，最稳。

## 常见问题速查

- **Key 填了连不上**：核对 Base URL 结尾（z.ai 官方是 `/api/anthropic`，DeepSeek 是 `/v1` 可省略）、Key 是否复制完整、账户是否有余额/额度
- **要代理的网络**：设置 ▸ 网络里配好代理再测
- **还是不行**：发邮件 **438251623@qq.com**，附上你配的端点类型与报错截图（**别发 Key 本身**）
